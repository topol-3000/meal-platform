# Architecture decision records

Decisions that hold for more than one service, or for the platform itself: the stack, how
services are built, deployed and talk to each other. A decision inside one service belongs
in that service's repository.

One file per decision, numbered in order: `0001-layer-first-code-organisation.md`. Each
says the context, the decision, its consequences and its status (proposed, accepted,
superseded by NNNN). An accepted ADR is not rewritten: a new one supersedes it.
